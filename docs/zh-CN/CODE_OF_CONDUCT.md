# 行为准则（Code of Conduct）

## 我们的承诺

我们希望 VibeBus 社区的参与对每个人都友好、专业且富有建设性，无论其背景、身份、经验或平台如何。

## 期望的行为

- 保持尊重、具体，并对善意的反馈持开放态度。
- 将讨论聚焦于行为、证据与软件本身。
- 保护他人隐私，并从公开讨论中移除凭据、恢复材料、本地数据库和个人数据。
- 对自己的错误承担责任，并帮助改进文档与测试。

## 不可接受的行为

骚扰、歧视、威胁、人身攻击、人肉搜索（doxxing）、蓄意披露他人隐私材料，或旨在阻碍他人参与的破坏行为，均不可接受。

## 执行

违反本政策时，维护者可以编辑、拒绝或移除贡献，并可能限制违规者的参与。请通过仓库的维护者联系方式或 GitHub 举报工具私下反馈行为问题。安全问题必须遵循 `SECURITY.md`，而不是通过公开举报处理。
