# 变更日志（Changelog）

## Unreleased

- 暂无未发布的变更。

## 0.11.0 - 2026-08-04

- 将首个 GitHub Release 修订为纯源码（source-only）契约：GitHub 自动提供带标签的源码归档，工作流只上传校验和、标准化 SBOM、供应链证据和源码发布清单。Windows 签名、安装程序、二进制 ZIP 与自行构建的源码 ZIP 推迟到单独的后续分发契约。
- 确立了公开开源发布契约：GitHub Releases 是官方分发渠道，稳定 SemVer 标签必须解析到可从 `main` 到达的提交，且预发布（prerelease）在拥有自己的已验证工作流之前保持禁用。
- 新增源码归档、发布证据清单字段、公开贡献与行为指引、Issue/PR 模板、Dependabot 更新、下载验证说明，以及明确的首装、升级和回滚规则。
- 新增基于原生 macOS Security.framework 钥匙串（Keychain）的 Agent 与 Operator 凭据存储，包括脱敏的注册/轮换、保险库（vault）回退、状态查询、显式删除，以及隔离的真实钥匙串验收 fixture。
- 新增原生二进制 macOS SessionStart/PostToolUse/Stop Hooks，沿用现有仅路径 Git、无日志测试、可靠退出与仅评审交接（handoff）边界。
- 新增 Apple Silicon 本地插件打包、ad-hoc 签名、清单/归档/校验和验证、已安装缓存验收，以及 macOS CI 任务。Developer ID 签名与公证（notarization）仍为生产门禁。
- 新增仅 CLI 的 `maintenance compact --backup <new-path>` 操作，带真实终端精确确认、基于保险库的 Operator 认证、快速失败（fail-fast）的 SQLite 排他锁，以及零活动状态强制检查。
- 在 `VACUUM` 之前要求新的已验证备份与保守的可用空间校验，随后恢复并 checkpoint WAL，并返回有界的压缩前后哈希、页计数、回收字节数与完整性证据。
- 新增 `compaction_started` 与 `compaction_completed` 审计事件，以及一次性项目对成功、活动状态拒绝、数据库繁忙拒绝和重定向输入不产生变更行为的覆盖。未向 MCP 添加压缩工具。
- 新增面向 Claude Code、Cursor、OpenCode 与 Antigravity 的多工具适配器包，附带共享的、与工具无关的 `vibebus-coordination` Skill 和通用生命周期 Hook 协议。
- 新增 Agent 生成桥接（`vibebus agent spawn|reply|kill|status` 及 MCP 工具），将外部 Agent CLI 派生为带任务/线程关联与事实总线结果捕获的受追踪会话。
- 新增 API 提供方注入：项目作用域的 `.vibebus/api.json` 提供方元数据配合 OS 保险库密钥，`api provider add|list|use|unuse|restore|health`、环境变量导出文件、`api run`、写前备份、冲突检测与审计事件。
- 新增能力注册表：`providers`、`skills` 与 `plugins` 表，配合 `skill register|list|install`、`plugin list` 与 `api sync-providers`，实现跨 Agent 能力复用。
- 将数据库 schema 扩展至版本 13，用于能力注册表与生成协调状态。
- 扩展了 CLI、MCP、生成、注入、注册表、迁移与跨工具验收覆盖。

## 0.10.0 - 2026-07-18

- 新增严格、有界的 `.vibebus/responsibility.json` 策略，将 Agent 角色映射到经校验的项目相对路径，同时仅在没有配置策略时保留允许一切（allow-all）的兼容行为。
- 为任务作用域的路径预留（reservation）、制品（artifact）声明与不可变的 Git 变更路径事实强制执行职责域。
- 新增经认证、会过期、由任务所有者签发、带语义幂等性与审计事件的跨域覆盖（override）；覆盖不能替代预留冲突控制。
- 新增不可变、任务作用域的 Git 提交与测试结果事实，带载荷有界、稳定重放、载荷漂移冲突、可选报告制品引用、CLI/MCP 对等性与上下文投影。
- 新增只读、有界的交接（handoff）提议命令与 MCP 工具。
- 新增确定性的 Codex `PostToolUse` 捕获，用于成功的 Git 提交与观察到的测试结果，以及一个在不发送交接、不读取转录的情况下写入可评审提议的 `Stop` Hook。
- 新增 schema-v11 迁移、策略/核心/CLI/MCP 覆盖、七项确定性 PowerShell Hook 检查与 CI Hook 验证。

## 0.9.0 - 2026-07-18

- 新增不可变、任务作用域的已确认决策（decision），带稳定语义键、任务所有者授权、制品引用、精确重放、载荷漂移冲突、幂等性与审计事件。
- 新增确定性的 Agent 上下文同步，覆盖进行中的所有自有任务、直接依赖、未读定向消息、相关制品与已确认决策。
- 新增条目数与序列化字节数预算、有界文本预览、不透明的单调续接游标（cursor），以及不读取制品文件内容的显式作用域元数据。
- 将无关任务事实及已确认或已关闭的消息从默认投影中排除。
- 新增 schema-v10 迁移、CLI/MCP 对等性、基于保险库的 MCP 覆盖、上下文隔离、语义去重、游标、预算与迁移测试。

## 0.8.0 - 2026-07-17

- 新增项目作用域的 Operator 凭据，其机密摘要与 Agent 持有者令牌隔离，且机密存储在 Windows 凭据管理器中的一个独立目标下。
- 新增仅 CLI 的交互式 Operator 初始化、轮换、保险库恢复、显式保险库删除、状态查询与留存计划批准；重定向输入、MCP 与常规自动化无法执行 Operator 变更。
- 要求每次新的留存应用都消耗一个未过期的批准，且该批准须绑定到确切的计划 ID 与当前 Operator 世代。
- 保留歧义结果的失败重试恢复：已完成的留存运行会重放其存储的报告，而无需或不会消耗第二个批准。
- 新增 schema-v9 Operator 凭据与留存批准审计表，以及留存报告与运行中的批准关联。
- 新增迁移、过期、轮换失效、并发单次消耗、保险库脱敏/恢复/删除、非交互拒绝、CLI 与 MCP 边界覆盖。

## 0.7.0 - 2026-07-17

- 新增 Windows GitHub Actions CI，覆盖格式化、锁定测试、Clippy-as-error、插件打包、MSI 验证、管理员解压与短生命周期工作流制品。
- 新增固定版本的 Rust 1.97.1 工具链与 WiX 4.0.6 本地工具清单。
- 新增按用户安装的 x64 MSI，将完整本地市场安装在 `%LOCALAPPDATA%\Programs\VibeBus` 下，并在不借助自定义动作的情况下更新当前用户的 PATH。
- 新增便携式市场与独立 Codex 插件 ZIP、SHA-256 校验和，以及机器可读的发布清单。
- 新增基于 SignTool 的 SHA-256 Authenticode 签名与验证，用于可执行文件与 MSI，使用临时 PFX 材料与 RFC 3161 时间戳。
- 新增失败即关闭（fail-closed）的标签发布：生产 GitHub Releases 要求两个签名机密、一个已存在的匹配语义化版本标签、通过发布门禁以及经过验证的制品。
- 新增仓库自有的插件与 MSI 验收脚本，兼容 Windows PowerShell 5.1 与 pwsh。

## 0.6.0 - 2026-07-17

- 新增在 Windows 凭据管理器中、使用当前用户通用凭据（Generic Credentials）的项目与 Agent 作用域机密存储。
- 新增明确的凭据存储与脱敏投递，用于注册、恢复与恢复密钥供给。
- 新增 CLI 与 MCP 从保险库的持有者令牌回退，同时保留显式参数与 CLI 环境变量的优先级。
- 新增凭据状态查询与显式删除操作，不将机密写入仓库或 SQLite 数据库。
- 新增轮换后保险库写入失败时的安全回退投递，防止不可逆的身份丢失。
- 新增可注入的内存保险库，以及针对隔离、优先级、脱敏、轮换、删除与失败恢复的核心与 MCP 覆盖。

## 0.5.0 - 2026-07-17

- 新增经认证的留存计划，带显式、绑定状态的确认 ID。
- 新增对旧事件前缀、幂等记录、已关闭消息历史、孤儿消息与终态任务/线程绑定的可重试（retry-safe）留存应用。
- 用最慢的已提交游标保护未读与待处理订阅范围，并始终保留一段可配置的近期事件尾部。
- 新增持久化留存历史下限、过期事件游标拒绝与快照安全游标钳制。
- 新增跨策略验证，确保已关闭消息存活时间超过其缓存的消息幂等响应。
- 新增 schema-v8 留存状态/运行审计表与 `retention_applied` 审计事件。
- 扩展了 CLI、MCP、迁移、并发应用、过期计划、游标缺口与待处理投递覆盖。

## 0.4.0 - 2026-07-17

- 新增由接收者拥有的消息关闭，对需要确认的消息采用先确认后关闭（ACK-before-close）规则。
- 将已关闭消息从常规收件箱（inbox）读取中隐藏，同时保留显式历史访问。
- 新增所有者作用域、可重试的任务到 Codex 线程绑定，并保证活动绑定唯一。
- 当任务变为已完成或已放弃时，自动解除活动任务/线程关联。
- 新增 schema-v7 绑定历史与消息收据生命周期字段。
- 扩展了 CLI、MCP、状态、交接快照、迁移、并发与终态覆盖。

## 0.3.0 - 2026-07-17

- 新增显式、可重试的订阅确认，推进已提交游标。
- 保留传统的轮询时消费（consume-on-poll）行为，同时防止其越过待处理投递。
- 新增 schema-v6 迁移字段，用于待处理与最近已确认投递状态。
- 扩展了 CLI、MCP、核心迁移、重放、空过滤器、冲突、并发与幂等 ACK 测试。
